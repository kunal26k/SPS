Part II — New Features (v2.0)

Three new features added to the Student Portal in the current release.

📺

Feature 1 — Live & Video Classes

Real-time and recorded class sessions, accessible from the student portal

New in v2.0

Feature Overview

New

Students and parents can access live class sessions and recorded lectures directly from the portal. Live classes show a real-time indicator with viewer count. Recorded sessions are stored and accessible after class ends.

Classes are organized by grade (Class IX, X, XI, XII) and subject. Students can filter by status (Live Now, Upcoming, Recorded) and join directly from the portal.

Sub-Features

New
🔴
Live Now indicator

Animated pulsing red dot, viewer count, session duration. "Join Now" button launches live session.

⏰
Upcoming class reminders

Students set reminders for classes not yet started. Countdown shown on card.

▶️
Recorded lectures library

All past sessions saved with date and duration. Searchable and filterable by subject.

📅
Weekly timetable view

5-day class schedule with color-coded subjects. Live classes marked with a ● indicator in the timetable.

🔍
Grade & status filters

Filter by Class (IX / X / XI), status (Live / Upcoming / Recorded), or subject.

User Stories

New

As a student, I can see all live classes happening right now and join with one click, so I never miss a class even when I can't be physically present.

As a parent, I can see my child's class schedule and which sessions they attended (live or recorded), so I stay informed about their learning.

As a teacher, I can schedule and launch sessions from the portal, with my class automatically notified beforehand.

📊

Feature 2 — Results & Attendance

Academic performance tracking and attendance calendar for students and parents

New in v2.0

Feature Overview

New

Students and parents can view detailed academic results and attendance records through the portal. Results show subject-wise marks, CBSE grades, performance progress bars, and term-to-term comparison. Attendance is displayed as a monthly calendar with color-coded days.

Results Sub-Features

New
🎯
Overall score ring chart

Animated circular progress chart showing overall % for the term with class rank badge.

📋
Subject-wise result table

Marks, CBSE grade (A1/A2/B1 etc.), progress bar, and term-on-term delta (▲▼) per subject.

📈
Term comparison cards

Side-by-side Term 1 vs Term 2 scores per subject with trend indicator.

⬇️
Downloadable report card

One-click download of the official report card PDF.

Attendance Sub-Features

New
📅
Monthly attendance calendar

Color-coded calendar: green (present), red (absent), amber (late), blue (holiday), dark (today). Month navigation arrows.

🍩
Attendance donut chart

Visual summary showing present/absent/late/holiday days with counts and percentages.

⚠️
Minimum threshold warning

Alert shown if attendance drops below 80% (CBSE minimum is 75%). Encouragement shown when above threshold.

⬇️
Downloadable attendance report

Printable monthly attendance summary.

User Stories

New

As a student, I can see my marks for each subject across terms so I know exactly where I'm improving and where I need more effort.

As a parent, I can view my child's attendance calendar from home and receive an alert if they are at risk of falling below the required attendance threshold.

➕

Feature 3 — Elective Course Enrollment

Students self-enroll in optional enrichment classes through the portal

New in v2.0

Feature Overview

New

Students can browse and self-enroll in optional elective classes beyond the standard CBSE curriculum — including AI & Coding, Music, Dance, Visual Arts, Robotics, Yoga, Languages, and more. Each student has a slot limit (4 electives max). Enrollment opens and closes on a fixed schedule.

Sub-Features

New
🗂
Course catalog with categories

Filter by Technology, Performing Arts, Visual Arts, Sports & Wellness, Language. 9+ electives available.

⚡
One-click enroll / drop

Toggle enrollment status on each course card. Enrolled courses show a green ribbon. Full courses show a "Full" disabled state.

🔢
Slot counter

Header shows "3 of 4 slots used" so students know their remaining capacity at a glance.

⚠️
Scarcity indicators

"2 spots left!" ribbon on near-full courses. Real-time available seats shown per card.

📋
My enrolled electives list

Summary list at the bottom showing all enrolled courses with schedule and a quick-drop option.

User Stories

New

As a student, I can browse elective courses online and enroll in the ones I want (up to 4), without having to fill a physical form or visit the administration office.

As a parent, I can see which electives my child has enrolled in, and check their schedule so I can plan pick-up times accordingly.

As a teacher, I can see how many students have enrolled in my elective course and track capacity in real-time.
